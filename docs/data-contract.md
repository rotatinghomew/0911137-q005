# 资料口径

intervals 是半开运行小时区间 [start_hour,end_hour)，负荷 load 是区间常数；不在区间内不累计暴露。events 的 kind 区分 failure、retire、inspection，known_hour 是获知时刻；repairs 的 overhaul 表示大修，minor 表示小修，不预先规定风险模型。机器编号不能跨站合并。基线提供事件计数与有效运行暴露；风险估计如何使用这些记录见 `risk-methodology.md`（故障与报废为竞争结局、大修按等级解释为年龄重置、小修不重置）。

## 现有资料

- `machines`：48 条本地记录。
- `intervals`：188 条本地记录。
- `events`：69 条本地记录。
- `repairs`：16 条本地记录。

所有日期、月份、周或小时均用各表中的整数业务时标，页面的分析时点使用同一单位。资料中的 known 字段表示该行信息何时对分析可见，不是数据载入时间。字段名按原始业务接口保留。

这些记录是项目随附的虚构业务数据，不包含真实员工、客户、交易或设备。`fixtures/data.json` 的表结构可通过资料查阅页面检查；服务不从外网补数。

## 分析版本

当前分析从同一份文件一次读取所有表，并把原始字节的 SHA-256 与筛选条件一起返回。保存分析时重新基于指定条件计算，保存的是结果值及该次资料指纹，而不是指向未来可变数据的引用。已有版本只读；同名保存产生另一条版本。历史结果保留原有字段语义，不因最新源文件被替换而重算。
